# KodNest Student Placement Tracker

A simple Python OOP project for managing student placement profiles.

## Project Overview

The **KodNest Student Placement Tracker** is a console-based Python application that allows users to add and manage student profiles, update mock scores, check placement readiness, change the platform name, and track the total number of students.

## Features

* Add student profiles
* Prevent duplicate Student IDs
* Display all student profiles
* Update student mock scores
* Validate scores between 0 and 100
* Automatically determine placement status
* Normalize student names
* Change the shared platform name
* Track total number of students
* Interactive menu-driven program
